# Security

Found a security problem in Kodiak Cleaner? Please report it privately, not in a public issue or review.

- Email **www.kodiakcleaner.app/contact** with the subject `[Security] Kodiak Cleaner`, or use the **Security** button under **Settings > Help > Contact & Feedback** in the app.
- Include the steps to reproduce it and what someone could do with it. Please don't include passwords or other personal data.

You'll get a reply as soon as possible, and a fix will be released before the details are made public.
