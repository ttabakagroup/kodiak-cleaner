# Releases

The newest downloads of Kodiak Cleaner, kept here as copies. Only the newest build of each app is kept, so the repository stays small. Every release is on the [Releases page](https://github.com/ttabakagroup/kodiakcleaner/releases), and the website has the same downloads at [www.kodiakcleaner.app](https://www.kodiakcleaner.app/).

**Windows** (`Windows-<version>-dev/`)

- `KodiakCleaner-Dev-Setup.msi`: the installer
- `KodiakCleaner-Dev-Portable.zip`: the portable version plus its Docs folder

**Mac** (`Mac-<version>-dev/`, Kodiak Cleaner for Mac)

- `KodiakCleaner-Dev-Mac.dmg`: the disk image
- `KodiakCleaner-Dev-Mac.zip`: the app in a ZIP

**Linux** (`Linux-<version>-dev/`, Kodiak Cleaner for Linux)

- `KodiakCleaner-Dev-AppImage.zip`: the AppImage plus its Docs folder
- `KodiakCleaner-Dev-Deb.zip`: the .deb package plus its Docs folder
