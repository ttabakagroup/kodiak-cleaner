Programs

  • Searchable list of installed programs, each with its own icon.
  • Uninstall several at once. Each one gets a registry backup, its own uninstaller, then a list of leftovers to remove.
  • Waits until an uninstaller has completely finished, including ones that hand over to a helper.
  • Repair, Rename and Delete Entry for broken or confusing listings (backed up first).
  • History records everything removed or changed, and Restore Selected puts it back where it can.

Registry

Finds entries that point at files or programs that no longer exist. Fifteen checks, all ticked to start:

ActiveX and Class IssuesApplication PathsApplicationsFontsHelp FilesInstallerMissing Shared DLLsMUI CacheObsolete SoftwareRun At StartupSound EventsStart Menu OrderingType LibrariesUnused File ExtensionsWindows Services
  • A Type column shows which check found each entry.
  • Fix everything, a selection, or one entry with a right-click.
  • Every fix is saved to a .reg backup first. Double-click a backup to undo.
  • Only reports an entry when the file or folder it points to is definitely gone from a local drive. Files in the Windows folder, drivers and core Windows services are never reported.

Scheduled Cleaning

  • Named cleanings, such as your browsers every week and Windows once a month.
  • Pick weekdays or a day of the month, a time, and the items.
  • Windows Task Scheduler starts Kodiak Cleaner, which cleans without a window and closes. Nothing runs in the background.
  • A cleaning missed while the PC was off runs at the next chance.
  • Items with a caution can't be scheduled.
New Schedule

Startup

  • Programs that start when you sign in, per user and for all users, each with its icon.
  • Turn them off or on one at a time or in a batch, just like Task Manager.
  • Add a program or shortcut to your Startup folder.
  • Removed entries are backed up first, and History can restore them, on or off as they were.

Tools

Eight Built-In Tools

Find what's taking space, spot what doesn't belong and look after Windows. Anything removed goes to the Recycle Bin first.

Browser Extensions

Lists extensions in Ablaze Floorp, Brave, Google Chrome, Helium, Microsoft Edge, Mozilla Firefox, Mullvad Browser and Vivaldi, with icons, versions and on or off state. Read-only, so you can spot ones you don't recognize.

Disk Analyzer

Shows how much space each folder takes and its share of the total, plus the 100 largest files. Drill into any folder and send a file to the Recycle Bin.

Drive Wiper

Overwrites free space (1, 3 or 7 passes), or securely erases a whole non-system drive with Windows' own format /P. Refuses the Windows drive and Kodiak Cleaner's own drive.

Duplicate Finder

Finds files with identical contents (size, quick hash, then full SHA-256). Removed copies go to the Recycle Bin, and the last copy is never removed.

Empty Folders

Finds folders with nothing inside and moves the ones you pick to the Recycle Bin. Windows, program and AppData folders are never searched.

Large Files

Lists the biggest files in a folder (50 MB and up, your choice). Windows, program folders and hidden or system files are skipped.

Scheduled Tasks

Lists the programs Windows runs on a schedule and turns them off or back on. Windows' own tasks are hidden unless you ask, and tasks are never deleted.

System Restore

Lists, creates and removes restore points, and opens System Restore to roll back. The newest point can't be removed.

System Information

Its own page at the bottom of the sidebar, between Settings and About. Read-only: nothing is changed.

Safety

Built-In Safety

  • Browsers are skipped while they're open, and files in use are skipped.
  • Cleaning folders are sanity-checked before anything is deleted.
  • Kodiak Cleaner runs as a normal user and asks for administrator rights only for system-wide items.
  • Program changes, registry fixes and startup removals are backed up first, and can be restored.
  • Risky Advanced Cleaning items carry a caution, ask before they're ticked, and never run on a schedule.
  • Symbolic links and junctions are never followed.
  • Every pop-up puts the safe choice first, so pressing Enter never does the risky thing.
  • Uninstalling leaves nothing behind, and asks before deleting your backups, logs and reports.

Privacy

Private and Local First

Nothing Collected

No telemetry, analytics, crash reports, accounts or ads. Nothing is sent automatically, ever.

Your Files Stay Yours

Settings, backups and the optional activity log are plain files on your own PC: in Documents\Kodiak Cleaner for the installed version, or beside the program for the portable one. Never in the cloud.

Updates Only When Asked

Kodiak Cleaner only goes online to check GitHub for updates, when you click Check Now or turn on automatic updates.

Feedback Through Your Email

In-app feedback opens your own email app. Nothing is sent until you press Send.

Docs Folder Included

The installer, the portable ZIP and the Mac and Linux downloads each come with a Docs folder: Changelog, Download, Homepage, License, Privacy, ReadMe and Terms of Use, all in plain text.
