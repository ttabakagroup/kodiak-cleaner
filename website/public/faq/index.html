About Kodiak Cleaner

Is Kodiak Cleaner Free?

Yes, with every feature, for everyone. There is no paid or Premium version, no trial and no upsell. It's also open source under the MIT License, so anyone may use it, read the code, change it and share it. More about open source.

What Does Beta Mean?

Kodiak Cleaner for Windows is in the Beta channel (versions 0.9), the last step before the first full release, 1.0. Every tool is there and more people are testing it, so it may still have bugs. It deletes things by design: check what's selected before you clean, keep your own backups of anything important, and please report anything that doesn't work under Settings > Contact & Feedback.

The changelog starts fresh with 0.9.0 Beta. About > All Changes Since the Start also lists the earlier Dev builds.

What Is Kodiak Cleaner?

A small, honest cleaner for Windows 10 and 11 (64-bit), with editions for Mac and Linux. It cleans junk files, browser data and program caches, fixes registry entries that point at things that are gone, manages startup programs and uninstalls programs with their leftovers. It also has built-in tools such as Disk Analyzer, Duplicate Finder, Hash Checker and Integrity Check. There are no ads, no bundled offers, no telemetry and no background services. See every feature.

Will My Dev Build Update to the Beta?

Yes. The Dev builds (0.8.x) ended with 0.8.121 Dev, and a Dev install that checks for updates is now offered the Beta. You can also run the Beta installer over it. Every channel installs to Program Files\Kodiak Cleaner, and updating keeps your settings, backups and supporter code.

Downloads and Updates

How Do I Check That a Download Isn't Damaged?

Open Hash Checker under Tools and drop the file on the page. Paste the hash from the download page into Expected Hashes, or drop the .sha256, .md5 or SHA256SUMS file that came with it. The file shows Verified when it matches, or Doesn't Match when it's damaged, changed or a different version. Hash Checker only reads your files and never sends them anywhere.

How Do Updates Work?

Click Check for Updates on the About page, or Check Now under Settings > Updates. Kodiak Cleaner asks its website whether a newer version is out. If there is one, it downloads the installer, checks it against the SHA-256 checksum the website lists, and installs it. Your settings, backups and supporter code are kept, and What's New shows what changed. Check for Updates Automatically is off until you turn it on.

Portable: replace KodiakCleaner.exe and keep KodiakCleaner.ini and the Backups, Logs and Reports folders next to it.

Installer or Portable: Which Should I Pick?

The installer (an MSI) suits most people. It adds Start menu shortcuts, installs updates for you and can skip the administrator prompt. The portable ZIP runs without installing, from any folder or a USB drive: extract it and run KodiakCleaner.exe. It keeps its settings, backups and logs beside the program instead of in Documents\Kodiak Cleaner.

Both are a single self-contained program, so there's nothing else to install. Go to the Download page.

Why Does Windows SmartScreen Warn Me?

Kodiak Cleaner is a free project, and its installer isn't code-signed yet. Until it is, Windows may show Windows protected your PC the first time you open it. That's expected: click More info, then Run anyway.

To check your copy is the real one, run Get-FileHash on it in PowerShell and compare the result with the SHA-256 on the Download page. If it doesn't match, or Windows shows a different warning, please don't run it, and contact us.

Help and Accessibility

How Do I Get Help or Report a Bug?

Use the Contact Us form and pick a topic: Bug Report, Feature Request, General Feedback, Accessibility or Security. In the app, Settings > Contact & Feedback opens the same form in your browser, and nothing is sent until you press Send. Ted reads every message.

How Do I Report a Security Problem?

Please report it privately through Contact Us with the Security topic, so it reaches Ted first.

Is Kodiak Cleaner Accessible?

We're working toward WCAG 2.1 at level AA and the Americans with Disabilities Act for the app and this website. The app is meant to work with the keyboard, gives buttons and icons text labels for screen readers, and every color scheme and accent meets WCAG 2.2 AA contrast. Under Settings > Appearance, the Text Size slider makes text, icons and buttons 80% to 200% of the normal size, and Animations can be turned off. This is an ongoing effort, so if something is hard to use with your setup, tell us. Read the accessibility statement.

Mac and Linux

Do the Mac and Linux Editions Have Every Tool?

Not yet. Windows is the most complete edition. The Mac and Linux editions are still Dev builds, with the same color schemes and the same privacy. The Full Feature List shows which edition has each feature, and supporter codes work in all three.

Is There a Linux Edition?

Yes. Kodiak Cleaner for Linux (version 0.8.23 Dev) is for 64-bit Linux with GTK 4 and libadwaita, as a DEB package for Debian and Ubuntu or an AppImage for any distribution. It has the Cleaner, Triggers and several of the Windows tools. Learn more about the Linux edition.

Is There a Mac Edition?

Yes. Kodiak Cleaner for Mac (version 0.8.16 Dev) is for macOS 26 or newer, on Apple silicon and Intel Macs. It has the Cleaner and Triggers, which shows everything that starts by itself. It isn't signed with an Apple Developer ID yet, so the first time, open it with Open Anyway in System Settings > Privacy & Security. See the steps and learn more.

Privacy and Safety

Does It Run in the Background?

No. There's no service and nothing running unless you open it. Scheduled cleanings are started by Windows Task Scheduler and close when they're done.

Does Kodiak Cleaner Send Anything Online?

No. There's no telemetry, analytics, crash reports, accounts or ads, and nothing is sent automatically, ever. Kodiak Cleaner for Windows only goes online to check for updates, when you click Check for Updates or turn on automatic checks. Buttons such as Support on Ko-fi, Get the Latest Driver and Contact & Feedback open your browser only when you click them. Integrity Check's Windows image repair uses Windows' own DISM tool, which may download repair files from Windows Update. The Mac edition has no network code at all, and the Linux edition never goes online by itself. Read the Privacy Policy.

How Do I Undo a Change?

  • Registry: every fix is saved as a .reg file in Backups\Registry first. Double-click it to put the keys back.
  • Startup and Programs: History restores removed entries, renames and removed leftovers. Uninstalls are only recorded, so install the program again to get it back.
  • Files: files removed by tools go to the Recycle Bin, so restore them from there. Mass Rename has Undo Last Rename.
  • Scheduled tasks: a deleted task is backed up first, and Restore puts it back.
  • Whole PC: System Restore creates restore points, and Driver Cleaner makes one before it removes drivers.

Is Kodiak Cleaner Safe to Use?

It only changes what you pick. Registry fixes, startup entries, scheduled tasks, program changes and drivers are backed up before every change, and files that tools find, such as duplicates, large files, empty folders and uninstall leftovers, go to the Recycle Bin. Browsers are skipped while they're open, files in use are skipped, and links and junctions are never followed. Advanced Cleaning shows a warning every time it opens, and Drive Wiper asks three times before it erases a drive.

Files the Cleaner deletes, wiped free space and erased drives can't be brought back, so look over each list before you click. More about built-in safety.

What Are Caution Items?

Some Advanced Cleaning items can cause harm, such as clearing saved browser passwords. They carry a caution, ask before they can be ticked, are never ticked for you, are skipped by Select All, and never run on a schedule or from the command line.

Where Are My Backups, Logs and Reports?

An installed copy keeps them in the Kodiak Cleaner folder in your Documents, and a portable copy keeps them beside KodiakCleaner.exe. Settings > Application has an Open Folder button. Settings are a plain KodiakCleaner.ini file, and nothing is kept in the cloud. Uninstalling asks whether to delete your backups, logs and reports.

Supporter Codes

How Do Supporter Codes Work?

Every feature is free. If you support Kodiak Cleaner on Ko-fi with $10 or more, you get a supporter code by email as a thank-you. Enter it under Settings > Supporter and click Apply Code. The code is checked on your computer only and is never sent anywhere, and it works in the Windows, Mac and Linux editions. Support on Ko-fi.

How Many Computers Does One Code Cover?

One supporter code covers up to 10 of your computers. Need more? Use the Contact Us form.

What Does a Supporter Code Unlock?

Only small thank-you extras: the Classic, Glacier and Lagoon color schemes, a Supporter badge (which you can hide), and the Support link goes away. Supporting never unlocks cleaning features or tools, and not supporting never takes anything away. See what's free and what's Supporter.

Using Kodiak Cleaner

Can I Hide Tools I Don't Use?

Yes, from 0.9.1 Beta. Under Settings > Tools, each tool can be turned off to hide it from the sidebar. You can also pin the tools you use most to Favorites at the top of the sidebar: right-click a page and pick Pin to Favorites, or drag it up.

Can I Run Kodiak Cleaner From the Command Line?

Yes, on Windows. Scripts and system administrators can clean, scan or fix the registry, and uninstall programs with no window, for example KodiakCleaner.exe /clean or KodiakCleaner.exe /registry /scan-only. Run KodiakCleaner.exe /help to see every switch. See the switches, examples and exit codes.

How Do I Make the Text Bigger?

Under Settings > Appearance, move the Text Size slider. It makes text, icons and buttons bigger or smaller in every Kodiak Cleaner window, from 80% to 200% of the normal size, on top of the display scaling set in Windows. Click Default Size to go back to 100%.

How Do I Move Kodiak Cleaner to a New PC?

Under Settings > Application, click Back Up Settings. It saves a dated copy of your settings and your Programs and Startup histories in Backups\Settings. Install Kodiak Cleaner on the new PC, close it, then copy those files over KodiakCleaner.ini and the two history.json files. Your supporter code is part of the settings, so it moves with them.
