Good to Know

File Names

The downloads keep the same names every release, with the channel in the name and the version in the release tag:

KodiakCleaner-Beta-Setup.msi
KodiakCleaner-Beta-Portable.zip

Release Channels

Dev (0.8.x) was early work, marked as a pre-release. Beta (0.9.x) is feature-complete and ready for wider testing, also marked as a pre-release. Stable (1.x) is the full release.

Every channel installs to the same folder, and installing one replaces another.

Version Numbers

The Beta started at 0.9.0 Beta on October 25, 2026, after the Dev builds 0.8.0 to 0.8.121. Its changelog starts fresh there.

Older Versions

Only the current Beta is offered for download. Older builds have been retired.

Newer versions include every fix from older ones, so the latest is always the one to use.

Checking a Download

Each file on a GitHub release page shows its SHA-256 checksum. Compare it with Get-FileHash in PowerShell. Kodiak Cleaner's own updater does this check for you.

Mac and Linux Editions

The Linux edition has its own version numbers, starting at 0.8.0 Dev on October 5, 2026. Its changelog is on the Linux page.

Its downloads are KodiakCleaner-Dev-Deb.zip and KodiakCleaner-Dev-AppImage.zip. Kodiak Cleaner for Mac started at 0.8.0 Dev on October 6, 2026; its changelog is on the Mac page.

Source Code

Every release is tagged in the repository (for example v0.9.1-beta), so the exact code behind any download can be read or built.
