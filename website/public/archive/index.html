Good to Know

File Names

Since 0.8.31 the downloads keep the same names every release, with the channel in the name and the version in the release tag:

KodiakCleaner-Dev-Setup.msi
KodiakCleaner-Dev-Portable.zip

From 0.8.31 to 0.8.36 the installer came as KodiakCleaner-Dev-Setup.zip. Earlier releases were named by version, such as KodiakCleaner-0.8.27-x64-msi-dev.zip.

Release Channels

Dev (0.8.x) is early work, marked as a pre-release. Beta (0.9.x) is feature-complete and ready for wider testing. Stable (1.x) is the full release.

Every channel installs to the same folder, and installing one replaces another.

Version Numbers

Version numbers restarted at 0.8.0 Dev on October 4, 2026, when Kodiak Cleaner was brought up to Ted's app standard. An earlier 1.2.0 preview was never published.

Older Versions

Versions marked "Not published" were development builds made before the GitHub repository opened, so they have no download. Their notes stay in the changelog.

Newer versions include every fix from older ones, so the latest is always the one to use.

Checking a Download

Each file on a GitHub release page shows its SHA-256 checksum. Compare it with Get-FileHash in PowerShell. Kodiak Cleaner's own updater does this check for you.

Mac and Linux Editions

The Linux edition has its own version numbers, starting at 0.8.0 Dev on October 5, 2026. Its changelog is on the Linux page.

Its downloads are KodiakCleaner-Dev-Deb.zip and KodiakCleaner-Dev-AppImage.zip. Kodiak Cleaner for Mac started at 0.8.0 Dev on October 6, 2026; its changelog is on the Mac page.

Source Code

Every release is tagged in the repository (for example v0.8.27-dev), so the exact code behind any download can be read or built.
