What Open Source Means Here

Read and Change the Code

Every line of Kodiak Cleaner for Windows, Mac and Linux is published under the MIT License. Anyone may read it, learn from it, change it and build their own copy.

Free for Everyone

Use it at home or at work, on as many computers as you like. No account, no trial and no paid version. Supporter codes only unlock two extra color schemes and a badge.

Nothing Hidden

No telemetry, ads or tracking code, in the app or on this website. What the code does is what the app does.

Share It

Pass Kodiak Cleaner on, put it on a USB drive for a friend, or include it in your own project. Just keep the copyright and license notice with it.

The Code

One Repository for Every Edition

The Windows, Mac and Linux apps, the installer and this website all live together in one GitHub repository.

Windows

C# with .NET 8 and WPF. The MSI installer is made with the WiX Toolset, and build.ps1 builds the installer and the portable ZIP.

Mac

A native SwiftUI app for macOS 26 or newer, for Apple silicon and Intel Macs.

Linux

Python with GTK 4, packaged as a DEB and an AppImage.
