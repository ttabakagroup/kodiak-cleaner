# Kodiak Cleaner 0.8.32 Dev

> [!WARNING]
> **Development build: use at your own risk.** More testing is needed before every feature can be confirmed to work as intended. Check what's selected before you clean and keep your own backups.

## Downloads

| File | What it is |
|------|------------|
| `KodiakCleaner-Dev-Setup.msi` | The installer. Best for most people. |
| `KodiakCleaner-Dev-Setup.zip` | The installer plus its Docs folder. |
| `KodiakCleaner-Dev-Portable.zip` | The portable version. Runs from any folder, no install. |

Windows 10 or 11, 64-bit. No telemetry, no ads, no upsells.

Website: [www.kodiakcleaner.app](https://www.kodiakcleaner.app/)

## What's New

### Appearance
- In every color scheme, the scheme's own accent is the first swatch. Classic's own accent is blue, so Classic no longer shows a second Blue swatch; its first swatch is named "Theme Accent (Blue)", and Blue chosen in another scheme becomes Classic's own blue there.
