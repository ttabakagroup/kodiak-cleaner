# Kodiak Cleaner 0.9.5 Beta

> [!WARNING]
> **Beta software: use at your own risk.** More testing is needed before every feature can be confirmed to work as intended. Check what's selected before you clean and keep your own backups.

Website: [www.kodiakcleaner.app](https://www.kodiakcleaner.app/)

## What's New in Windows 0.9.5 Beta

### Microsoft Store
- The 0.9.3 Beta try at putting Open Kodiak Cleaner in Windows 11's short Recycle Bin menu is removed from the Store package, since Windows never loads it there. The Recycle Bin setting now says to use Shift + right-click (or Show More Options) to find it.
