## What's New in Windows 0.8.39

### Settings
- A divider with a little space on each side now sits above Support Kodiak Cleaner at the bottom of the Settings sidebar, setting it and the privacy note apart from the pages above.

## What's New in Linux 0.8.2

- **Programs:** a searchable list of installed apps (system packages, Flatpak, Snap and menu entries) with multi-select Uninstall, leftover folder cleanup, Programs History and Repair.
- **Scheduled Cleaning:** named cleanings on chosen days through systemd user timers, Clean When You Sign In, and a Clean Now launcher action.
- **Tools:** Browser Extensions, Disk Analyzer, Drive Wiper, Duplicate Finder, Empty Folders, Large Files and System Information.
- **Backups and Logs:** a monthly activity log kept on your computer, plus Back Up Settings and Restore Settings.

## New: Kodiak Cleaner for Mac 0.8.0

- **A native Mac app** (SwiftUI) for macOS 26 Tahoe and later, on Apple silicon and Intel.
- **Cleaner:** system junk, browser data for Safari, Chrome, Firefox, Arc and more, app and developer caches, and Advanced Cleaning behind a warning.
- **Triggers:** one list of launch agents, launch daemons, cron jobs and shell startup files, with notes on suspicious ones. Every change is backed up first.
- **Not signed yet:** the first time it opens, macOS says it couldn't verify it. Open System Settings > Privacy & Security and click **Open Anyway**.
