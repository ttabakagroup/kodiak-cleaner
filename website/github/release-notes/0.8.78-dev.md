## What's New in Windows 0.8.78

### Interface
- While a tool is working (a scan, a clean, a wipe, a check), you can open other pages: a small card in the bottom right corner shows what it's doing, such as Scanning for Files or Optimizing Drives, with a progress bar and percentage in your color scheme and accent. Work with no way to tell how far along it is shows a moving bar instead. Click the card to go back to the tool, or the X to hide it until the next task.
- Closing Kodiak Cleaner while a task is still running asks first. Keep Open is the default; Close Anyway stops the task part way. Exit in the tray menu, Restart as Administrator and installing an update right away ask too.

## What's New in Linux 0.8.9 and Mac 0.8.5

- **Lagoon color scheme (Supporters):** deep blue and clear water, in light and dark, next to Honey, Classic and Glacier in Settings > Appearance.

## What's New in Linux 0.8.3

- **Fixes from a full review:** Old Kernels orders kernel versions by number, so the newest kernel is never mistaken for an old one; Old Log Files removes only rotated logs, not folders programs need; administrator cleanups skip /tmp and can't be redirected by a link; removing a cron job never rewrites an unreadable crontab; Clean When You Sign In works with any install path; a damaged settings file no longer stops Kodiak Cleaner from starting.

## What's New in Linux 0.8.2

- **Programs:** a searchable list of installed apps (system packages, Flatpak, Snap and menu entries) with multi-select Uninstall, leftover folder cleanup, Programs History and Repair.
- **Scheduled Cleaning:** named cleanings on chosen days through systemd user timers, Clean When You Sign In, and a Clean Now launcher action.
- **Tools:** Browser Extensions, Disk Analyzer, Drive Wiper, Duplicate Finder, Empty Folders, Large Files and System Information.
- **Backups and Logs:** a monthly activity log kept on your computer, plus Back Up Settings and Restore Settings.

## New: Kodiak Cleaner for Mac 0.8.0

- **A native Mac app** (SwiftUI) for macOS 26 Tahoe and later, on Apple silicon and Intel.
- **Cleaner:** system junk, browser data for Safari, Chrome, Firefox, Arc and more, app and developer caches, and Advanced Cleaning behind a warning.
- **Triggers:** one list of launch agents, launch daemons, cron jobs and shell startup files, with notes on suspicious ones. Every change is backed up first.
- **Not signed yet:** the first time it opens, macOS says it couldn't verify it. Open System Settings > Privacy & Security and click **Open Anyway**.
