# Kodiak Cleaner 0.9.4 Beta

> [!WARNING]
> **Beta software: use at your own risk.** More testing is needed before every feature can be confirmed to work as intended. Check what's selected before you clean and keep your own backups.

## Downloads

| File | What it is |

## What's New in Windows 0.9.4 Beta

### Microsoft Store
- Open Kodiak Cleaner is back under Show More Options on the Recycle Bin in the Store version. Windows 11 doesn't allow it in the short right-click menu there, and the 0.9.3 Beta try hid it from both menus.
