## What's New in Windows 0.8.121

### About
- Your Plan no longer reads "Free · unlocked by: None". On the free plan it just says Free.

### Drive Wiper
- Safer drive protection: if Kodiak Cleaner can't tell which disk holds Windows, Kodiak Cleaner itself, your user folder, your programs or a page file, or which disk Windows starts from, no drive can be erased, and each drive in the list says why.
- A wipe that stops partway because a drive was unplugged or couldn't be written now says so honestly: part of the drive was overwritten and its partitions are gone, so wipe it again to finish. It's written to the activity log too. The drive is set up again only when it's still attached as the same drive.
- The DoD 3 Passes hint only says the last pass is read back when it really is: on an Entire Drive wipe with Verify the Last Pass on.
- Drive names keep to the letters A to Z, numbers, spaces, hyphens and underscores, so they come out right on every PC. A line under the name box says so.
- The tick box next to Drive Name now reads Name the Drive.
- A drive that doesn't report a model is listed as "Disk 0: Unnamed Drive" instead of "Disk 0: Disk 0".
- The Letters column is wide enough for No Drive Letter.
- If reading the drives fails in an unexpected way, the page now shows what went wrong instead of staying on "Reading drives…".

### General
- When Kodiak Cleaner runs as administrator, links to the website, Ko-fi and Contact & Feedback open your browser normally, without administrator rights.
- Errors in background tasks are now written to the activity log.

### Getting Started
- The Hash Checker line now lists SHA-384 too.

### Support
- The support reminder now says every tool stays free, which is accurate: a few color schemes are a thank-you for Supporters.

## What's New in Linux 0.8.19 and Mac 0.8.12

- **Drive Wiper (both):** erase entire drives, like the Windows edition. Wipe Type Quick, Thorough or Secure; drives that hold the system, your home folder or Kodiak Cleaner can't be ticked; three checks before anything is erased (a summary, the drive's name typed in, then ERASE); progress with time left and a Stop button.
- **After wiping (both):** leave the drive uninitialized like a new one, or set it up with a recommended format for its type, shown in a notice above the choices and tagged Recommended. Linux offers exFAT, FAT32, NTFS and ext4; Mac offers APFS, Mac OS Extended (Journaled), exFAT and MS-DOS (FAT32).
- **Mac:** a new Tools section in the sidebar, with Drive Wiper (Free Space Only and Entire Drive) as its first tool.
- **Linux:** SSD and NVMe drives get their own firmware erase when they offer one, else a random overwrite; Verify the Last Pass reads every byte back.

## What's New in Linux 0.8.16 and Mac 0.8.11

## What's New in Linux 0.8.3

- **Fixes from a full review:** Old Kernels orders kernel versions by number, so the newest kernel is never mistaken for an old one; Old Log Files removes only rotated logs, not folders programs need; administrator cleanups skip /tmp and can't be redirected by a link; removing a cron job never rewrites an unreadable crontab; Clean When You Sign In works with any install path; a damaged settings file no longer stops Kodiak Cleaner from starting.

## What's New in Linux 0.8.2

- **Programs:** a searchable list of installed apps (system packages, Flatpak, Snap and menu entries) with multi-select Uninstall, leftover folder cleanup, Programs History and Repair.
- **Scheduled Cleaning:** named cleanings on chosen days through systemd user timers, Clean When You Sign In, and a Clean Now launcher action.
- **Tools:** Browser Extensions, Disk Analyzer, Drive Wiper, Duplicate Finder, Empty Folders, Large Files and System Information.
- **Backups and Logs:** a monthly activity log kept on your computer, plus Back Up Settings and Restore Settings.

## New: Kodiak Cleaner for Mac 0.8.0

- **A native Mac app** (SwiftUI) for macOS 26 Tahoe and later, on Apple silicon and Intel.
- **Cleaner:** system junk, browser data for Safari, Chrome, Firefox, Arc and more, app and developer caches, and Advanced Cleaning behind a warning.
- **Triggers:** one list of launch agents, launch daemons, cron jobs and shell startup files, with notes on suspicious ones. Every change is backed up first.
- **Not signed yet:** the first time it opens, macOS says it couldn't verify it. Open System Settings > Privacy & Security and click **Open Anyway**.
